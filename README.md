# Aqua Tower — página de enlaces

Sitio estático responsive para `xgroup-aquatower.proyecto.com.bo`, preparado para GitHub Pages.

## Publicación

1. Crear un repositorio en GitHub y subir estos archivos a la rama `main`.
2. En **Settings → Pages**, seleccionar **GitHub Actions** como fuente.
3. En el DNS de `proyecto.com.bo`, crear un registro `CNAME`:
   - Nombre: `xgroup-aquatower`
   - Destino: `<usuario-o-organización>.github.io`
4. Esperar la propagación y activar **Enforce HTTPS** en GitHub Pages.

El archivo `CNAME` ya contiene el dominio personalizado.
